# Saimo TV — Homebrew Channel

Catálogo personalizado para instalar o Saimo TV em TVs LG com webOS e Homebrew Channel.

## URL para adicionar no Homebrew Channel

`https://raw.githubusercontent.com/PedroMarioaBros/SaimoTV-Homebrew-Repo/main/api/apps.json`

No Homebrew Channel: Settings → Repositories → Add Repository. Cole a URL acima e confirme.

## Pacote

O catálogo aponta para o pacote oficial `SaimoTV-LG.ipk` da release 2.6.4 do projeto Saimo TV. O IPK é servido pelo repositório oficial de downloads do desenvolvedor; este repositório mantém o catálogo e o manifesto de instalação.

SHA-256: `c97edd359be1dcce65e800086630115dc9428029c268ad1ab7a509dd66f25ff0`

## Observação

Este catálogo não é oficial nem afiliado ao desenvolvedor do Saimo TV. A compatibilidade deve ser confirmada no modelo/versão do webOS da TV.
